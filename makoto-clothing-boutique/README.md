# Makoto Clothing Boutique — Website Package

A lightweight, responsive, no-payment boutique website built from the supplied Makoto promotional artwork.

## Included

- Responsive homepage / storefront
- Women's and Baby collections
- Category navigation
- Product cards and product detail modal
- Search
- Category filters
- Sample review system
- Video/media placeholders ready for real Makoto footage
- Booking / order request form
- WhatsApp message generation
- Direct call links
- Contact section
- Mobile navigation
- Natural hover and scroll interactions
- Accessibility-friendly focus states
- No payment gateway

## Important

The product images are cropped from the supplied Makoto promotional artwork. Replace them with the actual product photos when available.

The review content is explicitly marked as sample/demo content. Replace it with verified customer reviews before publishing as testimonials.

The video cards are placeholders. Replace them with Makoto's real video footage.

## Quick local test

Open `index.html` in a browser.

For a local server, from this folder run:

```bash
python -m http.server 8080
```

Then open:

http://localhost:8080

## Publish with Netlify

1. Create/log into a Netlify account.
2. Go to Netlify Drop:
   https://app.netlify.com/drop
3. Drag the entire `makoto-clothing-boutique` folder into the drop zone.
4. Netlify will publish the site and give you a `netlify.app` URL.
5. Rename/customize the site URL in Netlify if desired.
6. Later, connect GitHub for automatic deployments.

## Custom domain

After the first deployment, use Netlify's domain settings to connect a domain you own, such as:

makotoclothingboutique.com

Follow Netlify's DNS instructions exactly for the domain registrar you use.
